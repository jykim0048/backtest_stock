# 한국 주식시장 규칙 — 모든 역할이 공유하는 도메인 지식

미국 기준으로 쓰인 원본 프레임워크와 다른 점만 모았다. 각 역할 프롬프트는 이 파일을 전제로 한다.

## 거래 제도
- 정규장 09:00~15:30. 동시호가 08:30~09:00, 15:20~15:30. 결제 T+2.
- **애프터마켓 16:00~20:00**(2026-09 신설, 접속매매). 공식 종가·익일 기준가·가격제한폭은 **정규장 종가** 기준. 이 스킬의 "종가"는 정규장 종가다. ETF·ETN 제외.
- **가격제한폭 ±30%**(전일 종가 대비). 상한가·하한가 도달은 그 자체가 강한 수급 신호이며, 다음 날 갭·연속 상하한가 가능성을 리스크로 다룬다.
- **VI(변동성완화장치)**: 정적 VI = 직전 단일가 대비 ±10%, 동적 VI = 직전 체결가 대비 일정 % 급변 시 2분 단일가 전환. 하루 여러 번 발동은 투기적 과열 신호.
- **투자주의 → 투자경고 → 투자위험** 지정 단계. 투자경고 이상은 신용거래 제한·위탁증거금 100%·매매거래정지 가능. 지정 중 종목은 개인 수급이 왜곡되고 기관 접근이 제한된다.
- 단기과열종목 지정 시 3거래일 단일가 매매.

## 수급 주체 (투자자별 매매동향)
- **외국인, 기관계, 개인** 3대 주체. 기관계 세부: 금융투자(증권 자기매매), 투신(사모 포함), 연기금, 보험, 은행, 종금·저축, 기타금융, **기타법인**(일반 법인, 자사주 매입 포함).
- 해석 관행: 외국인·기관 **동반 순매수**는 가장 강한 긍정 신호, 개인 홀로 순매수 + 외인·기관 순매도는 경계. 연기금 순매수는 중장기, 금융투자는 단기(ETF·차익거래 영향 큼)로 본다.
- 단위 함정: KIS 허브 `daily` 는 **대금(백만원)**, 네이버 trend 는 **수량(주)**. 대시보드 표기는 억원. 섞어 비교하지 말 것.
- 확정 시각: KIS 일별 투자자 대금은 **15:40 이후 확정**. 장중 실행이면 당일 행이 비어 있을 수 있다(전일까지로 판단). 가집계 랭킹은 쓰지 않는다.
- **공매도**는 T+1 공표. 거래대금 대비 비중 10% 이상이 며칠 이어지면 하방 압력, 급감은 숏커버 가능성. 공매도 대금·대차잔고는 **시가총액 대비 비중(%)** 으로도 표기해 종목 크기가 달라도 비교할 수 있게 한다. **대차잔고** 누증은 공매도 대기 물량, 급감(상환)은 숏커버.

## 공시 (DART) 유형별 해석
- 상승 재료 후보: 단일판매·공급계약(규모를 최근 매출 대비 %로 환산), 수주, 무상증자, 자기주식 취득, 품목허가·임상 성공, 특허.
- 하락 재료 후보: 유상증자(특히 제3자배정 아닌 주주배정·일반공모), 전환사채·신주인수권부사채·교환사채(희석), 감자, 소송, 횡령·배임, 영업정지, 생산중단, 회생·파산.
- 중립·주의: 조회공시(풍문 답변), 최대주주 변경, 합병·분할(구조에 따라 양방향), 정정공시(원 공시 방향과 정정 내용을 반드시 함께 읽을 것).
- DART 목록은 **접수 날짜만** 있고 시각이 없다. 장 마감 후 접수 공시는 다음 날 반영된다. 촉매 판단 시 "이미 가격에 반영됐는지"를 접수일과 그 후 주가 반응으로 확인한다.

## 재무·밸류에이션
- 단위는 **억원**. DART 원본은 원 단위이므로 스크립트가 변환해 준다. 프롬프트에 억원으로 인용한다.
- 12월 결산이 대다수이나 3월·6월 결산 법인이 있다. 분기 라벨(Q1/H1/Q3/FY)은 12월 결산 가정.
- **금융업**(은행·보험·증권·지주)은 매출액·영업이익 개념이 다르다. 영업수익·순이익·ROE 중심으로 본다.
- 컨센서스(estPer·estEps·목표주가)는 증권사 3곳 이상일 때만 의미가 있다. 스몰캡은 결측이 흔하다.
- 밸류에이션 스냅샷(PER·PBR·목표가)은 **현재 시점 값**이다. 과거 시점 분석에 쓰지 말 것.

## 벤치마크와 성과
- 알파 기준: 코스피 종목은 **KOSPI(^KS11)**, 코스닥 종목은 **KOSDAQ(^KQ11)**.
- 보유 기간 기본 5거래일. 결정 로그의 실현 수익률은 정규장 종가 기준.

## 뉴스·여론 소스 특성
- 네이버 뉴스: 국내 언론, 속보성. 같은 내용의 기사가 여러 매체에 반복되므로 **건수로 강도를 재지 말 것**.
- 네이버 카페·종목토론방: 개인투자자 여론. 종토방은 공감/비공감 수로 쏠림을 본다. 낚시·홍보 글이 많다.
- 해외 뉴스·Reddit·StockTwits: 해외 뉴스와 StockTwits 는 **해외 peer 종목 기준으로 수집**한다. 한국 종목 직접 언급은 드물므로 **peer·섹터 맥락**으로만 쓴다.
- 증권사 리포트: 목표주가·의견은 코드가 원문 그대로 채운다. 매도 의견이 사실상 없으므로 "중립·목표가 하향"을 부정 신호로 읽는다.

## 표기 규칙
- 가격은 원 단위 정수(예: 269,500원). 진입가·손절가는 **절대 가격**으로 쓰고 %나 범위로 쓰지 않는다.
- 등락률·비율은 소수 1~2자리. 대금은 억원.
- 모든 서술은 한국어. 회사명·티커·기사 제목·URL 은 원문 유지.
- **리포트는 판단에 필요한 내용만 담는다.** 입력 파일명(`01_price.json` 등)·JSON 키(`hub.daily`, `relevance=company` 등)·단위 환산 과정·수집 경로(어느 API 로 가져왔는지)·실행 회차·직전 실행과의 비교는 쓰지 않는다. 단위는 결과값에만 표기한다(예: "억원"). 수집 실패나 데이터 불일치는 판단에 영향이 있을 때만 어느 값을 썼는지 한 줄로 밝힌다.
